# ML & DV Lab Experiments 

## Structure
- `ML/`: 9 Machine Learning experiment scripts.
- `DV/`: 8 Data Visualization experiment companion scripts.

## Setup
Recommended: Python 3.10+.

```bash
python -m pip install numpy pandas matplotlib scikit-learn
```

Some DV experiments need optional packages:
```bash
python -m pip install plotly seaborn squarify
```

Run an experiment from the repository root:
```bash
python ML/01_simple_linear_regression.py
python DV/01_powerbi_tableau_getting_started.py
```

## Important note about DV
The reference syllabus describes Power BI/Tableau practical tasks. These `.py` files are
Python companion implementations of the same visualization concepts; they are not
`.pbix` files or Tableau workbooks. If the instructor specifically requires Power BI
or Tableau project files, create and upload those separately.
